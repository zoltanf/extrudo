# The owner's UI review 3 (2026-10-11): items to address

**Status:** in progress, slice by slice (each item says where it landed); the
owner answered every question the same day ([Decisions](#decisions-owner-2026-10-11)). Written 2026-10-11 from the owner's
narrated screen recording of the app on `edge.extrudo.org` (12 min; kept on the
owner's machine, not in the repository) and two of the owner's screenshots from
the same day. The quotes are a machine transcript (Whisper `base.en`), so they
are close to the owner's words but not exact. Earlier reviews: ADR-0079 (round 1
and round 2 on 2026-10-08, round 3 the tile sizes).

Every item has an ID (`R3-nn`), what the owner said (with the time in the
recording), what the app does now, which docs say otherwise, and a proposed
change with acceptance checks. Every item is ready to build. Code pointers are
against `main` at `43407549`.

## Rules for whoever builds these

- One slice per branch off `main` (`ui3-<slice>-<slug>`), `pnpm check` passes,
  the e2e specs a slice touches run locally (`--workers=2`), the full suite
  through CI on the branch. Screenshot baselines that change come from CI's
  `playwright-report-*` artifacts (`--update-snapshots=all` locally on Arch is
  fine, check them in the Playwright Ubuntu image).
- Update the docs the item names (`docs/04-ui-spec.md` first), add a
  `docs/CHANGELOG.md` line, and record decisions as amendments of the ADRs named
  below (or a new ADR for R3-05 if it grows). Update `CLAUDE.md` where it states
  something an item changes (tab names, groups, e2e hooks).
- Other CAD tools are conceptual references only: no other CAD product's name
  in the UI (R3-04; Blender's preset keeps its name by the owner's choice), and
  never the f3d format's vendor anywhere in the repository.
- Tick the item here when it lands (`- [x]`, date, commit).

## Decisions (owner, 2026-10-11)

Answers to the five questions this plan first asked, the same evening:

1. **Mouse presets (R3-04):** "come up with inventive names for [the first two];
   we should unify this; Blender and Trackpad can stay, but we need better
   naming for these first three." Named Spindle, Crank and Glide (R3-04's
   table); Shift swaps orbit and pan in Spindle (the owner) and Crank (same
   rule).
2. **One search (R3-05):** "10 pins, in 2 rows."
3. **Right-click (R3-08):** "keep only the ring when that is selected."
4. **Tooltip clips (R3-16):** "let's do a first batch, and yes, I would
   re-record everything. Please make sure when recording that the important
   part is visible in the tooltip."
5. **P6-04 (i18n):** this review is the walk through the UI P6-04 waited for,
   but translations are **deferred**: "I don't want other languages than
   English at this point, we leave that for later." The roadmap's P6-04 says
   so; strings stay translation-ready (FR-UX-07).
