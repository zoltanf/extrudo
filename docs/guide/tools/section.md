# Section Analysis

Cut the view through a plane, with the cut filled in. Look inside without changing the model.

| Where | Shortcut |
|---|---|
| Construct › Inspect | Shift+S |

<video src="demo:section" muted loop autoplay playsinline aria-label="Section Analysis demo"></video>

<!-- notes -->
A named view saved while a section is shown keeps it: restoring the view puts the cut back. A view saved without a section leaves the one on screen alone.
