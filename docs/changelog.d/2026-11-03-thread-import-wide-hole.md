- 2026-11-03 · **A thread fills a hole past its root**: the kernel's fill (ADR-0056's fifth amendment) no longer refuses a hole at or past the thread's root — it fills it in like any wider hole, and only an untrimmable such hole (`ThreadFill.required`) is an error, since without the sleeve nothing would be cut; the `.f3d` importer imports a thread on a hole wider than the thread as drawn (ADR-0083's amendment), which the file's own resize of the hole did.
