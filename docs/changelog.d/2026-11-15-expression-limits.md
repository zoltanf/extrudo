- 2026-11-15 · **Limits on expressions**: an expression can be at most 10,000 characters long, a call takes at most 1,000 values, and parameters can use each other at most 10,000 levels deep; past a limit the expression is an error like any other, and an imported f3d file keeps that parameter's value instead. A cycle of more than 20 parameters says how many it goes through.
