- 2026-10-16 · **OpenSCAD export** (P6-09, ADR-0088): Export Model's fourth format, **OpenSCAD**, and `extrudo export --format scad` write the chosen bodies as one `.scad` file of real OpenSCAD code. Box, Cylinder, Sphere, Torus, Extrude and Revolve of sketch profiles and texts, Combine, Remove, Move, Mirror, Scale and the rectangular and circular patterns become primitives, `linear_extrude`/`rotate_extrude`, transforms and booleans; any other feature (fillet, chamfer, shell, loft, …) becomes a `polyhedron` of the body at that step, and later features build on it with CSG again, so a hole cut after a fillet stays a `difference`. The parameters the code uses become variables, the exposed ones in their group's Customizer section with their range and the rest hidden, and lengths, angles and counts are written as expressions over them where they translate. Sketch geometry stays fixed (OpenSCAD has no constraint solver), the same design gives the same bytes, and a guide page, OpenSCAD export, describes the file.
