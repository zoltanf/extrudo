- 2026-10-16 · **Import .f3d in a worker** (ADR-0083's amendment "import in a worker"): the importer runs in its own module worker instead of the UI thread, so a slow file no longer freezes the tab; a busy toast says "Reading the .f3d file…", an import that runs over 30 s (about six times the corpus's slowest) is stopped with "The import took too long", and a worker that dies or runs out of buffer memory ends in a message instead of a dead tab (a JavaScript-heap exhaustion is stopped only by the time limit).
