- 2026-11-25 · **Quicker edits before primitives, revolves, coils, sweeps, lofts and imports**: when you change an earlier part, a later box, cylinder, sphere, torus, coil, revolve by an angle, sweep or loft that makes a new body is no longer rebuilt, as long as it and its sketches sit on origin or construction planes not taken from another body's face; an imported STEP, mesh or OpenSCAD file is no longer read or compiled again either, so the model is ready sooner; and an import whose file hasn't arrived yet, or whose OpenSCAD compiler isn't downloaded yet, is tried again at the next recompute. In a test design of 50 revolved knobs, the recompute after an edit of the first knob drops from about 400 ms to under 20 ms.
