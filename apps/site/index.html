FAQ

Questions and answers

Short answers to what people ask first. The guide has the long ones.

Is Extrudo free?

Yes. Extrudo is free and open source under the GPL-3.0. There is no paid version and no account.

Do I need to install anything?

No. Open it in a current Chrome, Edge, Firefox or Safari and start designing. To give it a window of its own, install it from the browser's menu.

Is there a desktop app?

Yes, for Linux, Windows and macOS. It is the same Extrudo in a window of its own: it opens .extrudo files from your file manager and sends models straight to your slicer. Download and install it.

Where are my designs stored?

In your browser's own storage, on your computer. Nothing is uploaded, and the app has no analytics. To keep a copy or move a design to another machine, use Home › Export Design, which writes an .extrudo file. In Chrome and Edge you can also link a folder on your disk, and the desktop app saves to files.

Are my designs shared with others?

No. Extrudo has no server that keeps designs, so nothing you make is uploaded or seen by anyone else. A design only leaves your computer when you send it yourself: export it with Home › Export Design and share the .extrudo file, or export a 3MF, STL or STEP file of the model.

Does it work offline?

Yes. After the first visit the app is kept in your browser and opens without a connection. The one exception is the OpenSCAD compiler, which is downloaded the first time you import a .scad file.

Can I open files from other CAD programs?

STEP files come in as exact solid bodies, STL, 3MF and OBJ files as mesh bodies, and OpenSCAD files are compiled in your browser. The latest build also reads .f3d files. The features page has the full table of formats.

Which slicers does it work with?

Any slicer that opens 3MF or STL. A 3MF file keeps your bodies' names, colours and units. The desktop app can also open the model straight in PrusaSlicer, OrcaSlicer, Bambu Studio or Cura.

Can I automate a design?

Yes. A Script feature runs TypeScript inside the design, a recorded macro gives you the code for what you just did, and plugins add features of their own. The API docs cover all three.

Is it ready for real work?

It is young and changes quickly. Designs saved by an older version keep opening in newer ones, and the file format is documented. Still, export a copy of the designs that matter to you.

How do I report a problem or ask for a feature?

Open an issue on GitHub, or write to __CONTACT_EMAIL__. To help with the code, start with CONTRIBUTING.md.
