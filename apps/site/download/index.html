Desktop app

Extrudo on your desktop

The same Extrudo as in the browser, in a window of its own. It opens .extrudo files from your file manager, keeps designs as files on your disk, and sends models straight to PrusaSlicer, OrcaSlicer, Bambu Studio or Cura.

The installers are not signed yet, so your system asks before the first start. Each section below says what to choose.

Windows

64-bit Windows (x64).

  1. From the latest release, download the file ending in win-x64.exe.
  2. Run it. Windows may say it protected your PC, because the installer is not signed yet: choose More info, then Run anyway.
  3. Choose whether to install it for you alone or for everyone on the computer, and in which folder.
  4. Start Extrudo from the Start menu.

Updates

Extrudo downloads a new version in the background and tells you when it is ready. Press Restart, or let it install the next time you quit. Your open designs are saved first.

macOS

A Mac with Apple silicon (M1 or newer).

With Homebrew

brew install --cask zoltanf/extrudo/extrudo

Or by hand

  1. From the latest release, download the file ending in mac-arm64.dmg.
  2. Open it and drag Extrudo into Applications.

The first start

Extrudo is not signed with an Apple certificate yet, so macOS says it can't be opened. Open System Settings › Privacy & Security and choose Open Anyway next to Extrudo. You do this once for each install.

Updates

Extrudo tells you when a new version is out. Update with brew upgrade, or download the new dmg.

Linux

64-bit x86 (x86_64).

AppImage, for any distribution

From the latest release, download the file ending in linux-x86_64.AppImage, then make it executable and run it: 

chmod +x extrudo-*-linux-x86_64.AppImage
./extrudo-*-linux-x86_64.AppImage

On Arch-based systems (Arch, Omarchy, Manjaro) an AppImage needs fuse2: sudo pacman -S fuse2. The AppImage updates itself, like the Windows app.

A .deb, for Debian and Ubuntu

Download the file ending in linux-amd64.deb and install it:

sudo apt install ./extrudo-*-linux-amd64.deb

Extrudo tells you when a new version is out. Install the new .deb the same way.

Your designs from the browser

The desktop app keeps its own designs, apart from the ones in your browser. To bring a design over, export it in the browser with Home › Export Design and open the .extrudo file in the desktop app.

On your own server, with Docker

The browser app as a container: nginx with the same build as app.extrudo.org, for x86-64 and ARM (a Raspberry Pi or an ARM NAS). Nothing leaves it: no telemetry, no outbound requests, no internet needed once pulled. 

docker run -d -p 8080:80 ghcr.io/zoltanf/extrudo:latest

Then open http://localhost:8080. latest is the last release; 0.8.0 pins a version; edge is the latest build of main.

Over plain HTTP on a LAN address browsers hold back the offline mode and the install as an app; put it behind a reverse proxy with HTTPS and everything works as on app.extrudo.org.
